# Vlad Landing System

Бесплатная рабочая дизайн-система для лендингов и небольших сайтов.

## Основа

- HyperUI — источник паттернов и готовых Tailwind/HTML-блоков.
- Tailwind CSS — базовая система стилей.
- Lucide — иконки.
- Нативный HTML/CSS/JS — приоритет для блоков, которые должны работать в Tilda.

HyperUI используется как open-source источник под MIT License. Компоненты не копируются автоматически: перед использованием конкретного блока его нужно адаптировать под правила этого репозитория и задачу проекта.

## Как использовать с ChatGPT

В новой задаче достаточно написать:

> Используй мой GitHub-репозиторий `vlad-landing-system` как дизайн-систему.

И затем описать страницу или блок.

Примеры:

- «Сделай первый экран для проктологии по моей дизайн-системе».
- «Собери лендинг косметологии по моей дизайн-системе и отдай код блоками для Tilda».
- «Переделай этот блок так, чтобы он соответствовал моей дизайн-системе».

## Приоритеты системы

1. Конверсия и понятность важнее декоративности.
2. Один экран — одна главная мысль.
3. Минимум визуального шума.
4. Сильный CTA должен быть виден без поиска.
5. На мобильном интерфейс проектируется отдельно, а не просто сжимается.
6. Медицинские проекты не используют неподтверждённые обещания результата.
7. Код для Tilda должен быть автономным и по возможности без тяжёлых зависимостей.

## Структура

- `AGENTS.md` — инструкция для ChatGPT/AI-агента.
- `DESIGN-SYSTEM.md` — визуальные и UX-правила.
- `rules/landing-rules.md` — правила построения лендингов.
- `rules/tilda-rules.md` — требования к коду для Tilda.
- `styles/tokens.css` — стартовые дизайн-токены.
- `components/` — утверждённые блоки и компоненты.

## Статус

Система развивается по мере работы. Хорошие решения из реальных проектов можно добавлять в `components/`, чтобы использовать повторно.
